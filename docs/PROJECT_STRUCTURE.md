# Project structure

```
Yii3-Enterprise-Platform/
├── assets/                     UI sources published by yiisoft/assets (admin/app.css, admin/app.js, vendor/htmx.min.js)
├── config/
│   ├── configuration.php       yiisoft/config groups (routes list, di, params, environments)
│   ├── common/
│   │   ├── params.php          all environment-driven platform parameters (platform.*)
│   │   ├── settings.php        typed runtime settings registry (SettingsService)
│   │   ├── permissions/*.php   RBAC catalog per module (./yii rbac:sync)
│   │   ├── jobs.php + jobs/    job type → handler map
│   │   ├── events.php + events/ Kafka consumer groups
│   │   ├── notification-channels.php + notification-channels/
│   │   └── di/*.php            DI definitions, one file per module
│   ├── console/                commands.php (+ commands/*.php), console DI
│   ├── web/di/                 HTTP pipeline (global middleware), CurrentUser, view injection
│   ├── environments/{dev,test,prod}/params.php
│   └── routes/
│       ├── auth.php web.php admin.php api-v1.php system.php webhooks.php
│       ├── admin/NN-section.php   one file per Control Center section (01–24, 22a Gii, 23a/23b modules)
│       ├── web/*.php              module web routes
│       └── api-v1/*.php           API routes
├── src/
│   ├── Admin/                  Action/<Section>/*Controller.php, Menu/AdminMenu.php, Middleware/
│   ├── Web/                    Action/*, Auth/WebAuthSession.php, Middleware/ (login, permissions, step-up, locale, gates)
│   ├── Api/V1/                 Action/*, Http/, Middleware/, OpenApi/
│   ├── Platform/               reusable platform modules
│   │   ├── Identity/           users, auth, MFA, sessions, API tokens, Sso/ (OIDC, OneID, OAuth2)
│   │   ├── Access/             RBAC catalog, synchronizer, AccessService
│   │   ├── Tenancy/ Organizations/ Api/
│   │   ├── Settings/ FeatureFlags/ Audit/ Security/
│   │   ├── Queue/ Scheduler/ Messaging/ (Outbox, Kafka) Maintenance/
│   │   ├── Notifications/ Integrations/ Workflow/ Modules/
│   │   ├── Monitoring/ (health, metrics, tracing, Prometheus) Incidents/ Backup/ Deployments/ Infrastructure/
│   │   ├── Database/ Redis/ Storage/
│   │   ├── Gii/                Enterprise Gii (generators + templates on top of yiisoft/yii-gii)
│   │   └── Setup/              seeder
│   ├── Modules/
│   │   ├── Projects/           hand-written reference business module
│   │   └── Contracts/          module generated by Enterprise Gii
│   ├── Shared/                 Domain (exceptions, Uuid), Infrastructure (DB, Redis, cache, HTTP, logging, security, views)
│   └── Console/Command/        install, seed, demo, rbac:sync, queue:work, scheduler:run, outbox:relay, kafka:*, audit:verify
├── resources/
│   ├── views/{admin,web,auth,layouts,components,errors,api}/
│   └── messages/{uz,ru}/app.php   translations (source strings are English)
├── migrations/                 SQL migrations (yiisoft/db-migration)
├── public/                     index.php, static/ (icons, swagger-ui), api/openapi.json, assets/ (published)
├── tests/{Unit,Integration,Api,E2E,Security,Performance,Support}
├── infra/
│   ├── docker/{php,nginx,postgres,redis,s3}
│   ├── kubernetes/{base,overlays/{staging,production},examples}
│   ├── terraform/  ansible/
├── observability/{prometheus,alertmanager,grafana,otel}
├── scripts/                    platform.sh (dev entrypoint), ci/*.sh, i18n-extract.php
├── docs/                       this documentation
├── compose.yaml  Makefile  .gitlab-ci.yml  .github/workflows/ci.yml
└── composer.json / composer.lock
```

Rules: actions and views live in separate trees; business logic lives in application services; every module
registers itself only through files in its own `config/**/<module>.php` slots (no edits of shared files).
